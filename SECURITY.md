# Security Policy

## Supported Versions

Currently, the project is in the research and prototype phase. There are no production-ready versions supported for security updates at this time.

## Reporting a Vulnerability

If you discover a security vulnerability, including incorrect cryptographic assumptions or flawed evidence parsing, **do not open a public issue.** 

Please email the maintainer directly. Validated reports will be patched, and coordinated disclosure will be provided once a fix is merged.
